# 🏦 Banking System

A full-stack banking web application built with Django and styled with modern HTML, CSS, and JavaScript. Users can register, log in, and perform banking operations like deposit, withdrawal, and fund transfers.

## Features

- User registration and login with authentication
- View account balance and unique account number
- Deposit money with quick amount buttons
- Withdraw money with balance validation
- Transfer funds to other accounts
- Full transaction history with filter by type
- Clean responsive dark-themed UI

## Tech Used

- **Backend:** Python, Django, SQLite
- **Frontend:** HTML, CSS, JavaScript
- **Auth:** Django built-in authentication
